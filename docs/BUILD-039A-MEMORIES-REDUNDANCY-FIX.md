Build 039a is a surgical follow-up to Build 039.

- writing areas, Companion, Footer and page geometry remain unchanged;
- the physical A5 page remains literal white;
- no `.nls` migration or schema change;
- no refactoring or unrelated visual adjustment.

The application version remains `0.39.0-alpha.1`; this is a correction package for the approved Build 039 state, not a new feature version.

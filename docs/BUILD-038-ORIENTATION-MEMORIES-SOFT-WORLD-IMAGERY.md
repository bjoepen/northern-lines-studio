# Build 038 — Orientierung & Erinnerungen · Soft World Imagery

Build 038 converts the two utility pages from technical labels into Northern Lines Travel Language and corrects their image grammar.

## Orientation

The former **Inhaltsverzeichnis** is now **Orientierung** everywhere the traveler sees the page. It is deliberately image-free. Its role is navigation, so typography, section grouping and page numbers remain the complete visual hierarchy.

Internal persistence keys (`contents`) remain unchanged for format compatibility.

## Memories

The former **Notizen** page is now **Erinnerungen**. The established writing grammar remains: a large free area plus Schnellnotiz, Ideen and Skizze. One fixed world-owned Curated Accent remains allowed because atmosphere is useful here, but writing capacity remains authoritative.

Internal persistence keys (`notes`) remain unchanged for format compatibility.

## Soft world imagery

Curated world imagery no longer ends in a hard rectangular tile. Fjord and Ostsee hero assets and the Erinnerungen accents use baked transparent, softly feathered watercolor edges. This is an asset treatment, not a user option.

The image treatment must preserve:

- literal white page surface;
- open white space around the artwork;
- no border, card or tile treatment;
- the same Hero grammar and dimensions already approved for Interest and Workshop pages;
- Companion, Footer and Content Fit priority.

## Compatibility

No `.nls` migration is required. Existing page type and role identifiers remain unchanged.

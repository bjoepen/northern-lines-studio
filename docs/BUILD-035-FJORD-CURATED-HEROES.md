# Build 035 — Fjord Curated Heroes

Build 035 introduces fixed, world-owned miniature heroes for the Fjord Editorial World.

## Scope

Curated heroes are added to:

- Fotografie (Interest Page)
- Wandern & Natur (Interest Page)
- Kultur & Geschichte (Interest Page)
- Kulinarik & Lokal (Interest Page)
- Fotografie-Workshop

No hero picker, upload, replacement, visibility toggle or `.nls` field is introduced.

## Grammar

The Fotografie-Workshop is the maximum-size reference. The hero only occupies the upper-right header area. Introductory copy may flow around it. Once the header flow ends, the existing modules return to their established full content width.

Companion and Footer remain protected. Capacity Protection remains authoritative.

## World ownership

Assets live below `public/design-library/worlds/fjord/curated-heroes/`. They are Studio/World assets and are not copied into travelbook projects.

Build 035 intentionally implements Fjord first. Ostsee remains unchanged until its own visual hero set is approved.

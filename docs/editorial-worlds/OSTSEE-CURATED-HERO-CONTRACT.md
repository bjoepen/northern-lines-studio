## Binding behavior

- no picker, upload, replacement or visibility toggle;
- no `.nls` persistence for the hero itself;
- active World selects the hero automatically;
- hero lives only in the upper-right header flow;
- intro copy may wrap beside / below it;
- all following modules return to their established full width;
- Workshop remains the maximum-size reference;
- Companion and Footer are not displaced;
- Capacity Protection may reduce hero presence before compressing core content;
- page surface stays `#FFFFFF`.

## Ostsee expression

The Ostsee set reads lighter and more horizontal than Fjord while remaining unmistakably Northern Lines:

- coast, dunes, sand, reeds;
- quiet Baltic water;
- harbour / jetty motifs;
- Hanseatic / historic waterfront character;
- local fish-market context;
- Sand / Fog / Steel with restrained Amber warmth.

The World changes expression, never semantic meaning.

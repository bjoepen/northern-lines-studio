# Build 036 — Ostsee Curated Heroes

Build 036 applies the approved Curated Hero contract to the **Ostsee Editorial World**.

## Scope

Fixed, World-owned heroes are supplied for:

- Fotografie
- Wandern & Natur
- Kultur & Geschichte
- Kulinarik & Lokal
- Fotografie-Workshop

The user cannot choose, replace, hide, upload or otherwise edit these images. The hero is not `.nls` travelbook content.

## World expression

The Ostsee set follows the same semantic roles and layout grammar as Fjord, while expressing the Ostsee World through:

- sand and dune landscapes;
- quiet horizontal coastal space;
- Baltic harbours and jetties;
- Hanseatic / historic harbour architecture;
- local fish-market imagery;
- a lighter Sand / Fog / Steel / Amber visual balance.

The physical page surface remains literal `#FFFFFF`.

## Layout grammar

The Fjord Curated Hero Contract remains authoritative:

- hero is embedded only in the upper-right header flow;
- introductory copy may flow beside and below the hero;
- after the intro, flow ends explicitly;
- content modules resume the established full-width geometry;
- Fotografie-Workshop remains the maximum-size / worst-case reference;
- Companion and Footer remain invariant;
- Content Fit / Capacity Protection remain authoritative;
- no persistent split column is created.

## Asset ownership

Assets live under:

`public/design-library/worlds/baltic/curated-heroes/`

The registry is selected from the active Editorial World. Switching Fjord ↔ Ostsee changes World expression automatically without changing page semantics.

No `.nls` migration is required.

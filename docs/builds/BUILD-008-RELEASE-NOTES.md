# Build 008 Release Notes

## Story Components Foundation

Build 008 adds the first semantic Story Components layer to Northern Lines Studio while deliberately preserving the quiet Build-007 interface.

The selected page can now be interpreted as a structure of meaningful expressions rather than a list of technical objects. For a Destination this includes Hero, title, introduction, place knowledge, photography, Northern Lines knowledge, QR and optional expressions such as souvenirs.

The Editorial Frame remains separate and carries the recurring Header, Footer, dynamic page number and Editorial Companion.

No authoring feature or project format migration is introduced in this build.

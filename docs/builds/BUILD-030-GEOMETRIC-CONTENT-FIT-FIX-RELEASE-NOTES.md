# Release Notes – Build 030 Geometric Content Fit Fix

Dieser Fix beseitigt einen zu früh auslösenden Capacity-Warnzustand auf Interest Pages.

Studio verwirft eine zulässige Komposition nicht mehr allein aufgrund pauschaler Zeichenmengen. Der Geiranger-Zwei-Routen-Fall bleibt mit dem vollständigen Skageflå-Sicherheitshinweis renderbar. Der bekannte Overflow-Hinweis bleibt weiterhin autoritativ, sobald keine erlaubte Komposition in der geschützten Content-Zone Platz findet.

Keine Schemaänderung. `.nls` bleibt 0.14.0.

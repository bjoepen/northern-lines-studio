# Build 009 – Companion Collection Foundation

Build 009 establishes Editorial Companions as a first-class Northern Lines design-system concept.

## Delivered

- `src/lib/companions/` registry and domain types
- `design-library/companions/` manifest, metadata and retained source assets
- active Fjord mapping: `fjord -> fjord-puffin`
- planned concepts for Baltic, Britain, Woodland, Iberian, Canary and Arctic
- unassigned squirrel candidate retained without inventing a World
- tests for uniqueness, active-World assignment, metadata alignment and asset presence
- explicit Canary transparency-review flag

## Non-goals

- no second Editorial World
- no Companion image rendering in Studio
- no automatic placement
- no animation
- no Publisher bridge execution
- no `.nls` migration

## Product principle

A Companion accompanies the journey. It never becomes the journey.

# Release Notes — Build 031

Northern Lines Studio führt wiederverwendbare **Travel Companion Pages** ein. Die Seite **Licht** enthält nun einen fundiert recherchierten, kuratierten Northern-Lines-Kern und kann mit einem kurzen Hinweis für die konkrete Reise ergänzt werden.

Das Projektformat steigt von `.nls` 0.14.0 auf 0.15.0. Die Migration erfindet keinen Reisehinweis; sie ergänzt ausschließlich die passende semantische Komponente für bestehende Licht-Seiten.

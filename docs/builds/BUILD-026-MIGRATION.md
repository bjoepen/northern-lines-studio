# Build 026 · Migration 0.10.0 → 0.11.0

Opening a Build-025 project updates `formatVersion` from `0.10.0` to `0.11.0`.

Migration preserves:

- Journey and route
- Destination IDs and content
- imagery
- Editorial Extensions
- Editorial World selection
- page effects

Migration creates **no** interest pages automatically. A thematic page exists only after the traveller explicitly chooses an interest in Studio.

# Build 004 – Release Notes

## Reference World Foundation

Northern Lines Studio 0.4.0 introduces **Fjord** as Reference World 001.

Projects now reference `fjord` by ID while Studio owns the World definition, including the Papageientaucher as Editorial Companion, the calm image-led design-language descriptors and the set of supported page grammars.

The central A5 preview is now responsive. It scales proportionally with the available workspace when the window is resized or maximized, while preserving breathing room and a deliberate maximum size.

The UI remains intentionally restrained: no new toolbar, DTP palette or editing surface has been introduced.

`.nls` format 0.3.0 remains compatible with the 0.2.0 and 0.1.0 migration paths.

# Build 021 – Release Notes

## Layout Resilience & Content Capacity Foundation

Build 021 refines the A5 Destination composition without expanding product scope.

### Neu

- 17 mm Binding Safe Area for Destination previews
- Title Safe Area with corrected subtitle spacing
- Companion Safe Area at the Footer threshold
- three-column editorial module composition where context supports it
- internal non-destructive content-capacity states
- automatic Travel-Language **Uhr** presentation for arrival/departure
- new Build-021 consistency gate

### Verbessert

- Schutz ungespeicherter Ortsprofil-Änderungen wieder vollständig hergestellt: **Verwerfen · Abbrechen · Speichern** vor Seitenwechseln und geschützten Reiseaktionen
- `docs/PRODUCT-DNA.md` als dauerhafte Referenz neben README, VISION und ARCHITECTURE aufgenommen

- **Weite** uses the upper page area more efficiently
- Practical Info no longer needs to occupy a full-width lower row when three peer modules are present
- Companion starts after the binding-safe edge and remains stable across all three page effects

### Unverändert

- `.nls` 0.8.0
- Destination Domain model
- three page effects: **Weite**, **Bild links**, **Bild rechts**
- Publisher/Studio boundary
- Footer language and Fjord companion identity

### Nicht enthalten

No new Destination fields, Souvenir/country-rule editor, Asset Management, Crop/Focal Point, free layout, new Editorial World or Publisher rearchitecture.

# Build 032 · Travel Companion Master: Wetter

Build 032 setzt die zweite Travel-Companion-Seite auf Basis des in Build 031 etablierten Masters um.

## Scope

- kuratierte Wetterseite mit vier allgemeinen Situationen: Regen & Nässe, Wind & Böen, Nebel & Sicht, Wolken & Wandel;
- optionaler reisespezifischer Hinweis **Für diese Reise**;
- Shared Travel Companion Master von `Licht`;
- Inspector-Typografie für Travel Companion Pages vereinheitlicht;
- `.nls` 0.16.0 mit Migration von 0.15.0;
- keine Live-Wetterdaten, keine Ortsprognosen, keine erfundenen regionalen Werte.

## Nicht im Scope

- Wetter-API / Live Forecast;
- Warnungs-Pushes;
- automatische Destination-Klimadaten;
- frei konfigurierbare Dashboard-Widgets.

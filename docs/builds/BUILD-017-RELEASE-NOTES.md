# Build 017 – Release Notes

Northern Lines Studio zeigt eine Reise nun erstmals sichtbar als Teil ihrer Editorial World.

Die Fjord Reference World bringt eine eigene Layout Language mit: ruhige Fjord-Farben,
nordische typografische Haltung, world-spezifische Seitendetails und einen
wiederkehrenden Northern-Lines-Footer.

Für Destination-Seiten sind bewusst nur drei spätere Varianten vorbereitet:
**Weite**, **Bild links** und **Bild rechts**.

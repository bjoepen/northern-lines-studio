# Build 010 Release Notes – Story Authoring Foundation

Northern Lines Studio can now move from understanding a story to writing it. Select a Story Component in the Inspector, write or revise its semantic content, set its editorial status and save it directly into the `.nls` project.

The release intentionally adds no text-formatting toolbar and no freeform page objects. Meaning remains the authoring surface; presentation remains the responsibility of Editorial Grammar and the Publisher.

# Build 025C · Ostsee Warm Expression Polish

## Entscheidung

Die A5-Seitenfläche bleibt in jeder Editorial World weiß. Ostsee erhält ihre wärmere Identität über gezielte redaktionelle Flächen und Akzente – nicht über eine eingefärbte Seite.

> Die Seite bleibt weiß. Die World spricht über ihre Inhalte und Akzente.

## Änderung

- Ostsee-Seitenfläche explizit auf `#FFFFFF` gesetzt.
- `paperTone` der Ostsee Layout Language auf `#FFFFFF` vereinheitlicht.
- Ostsee-Palette um **Backstein** ergänzt; Bernstein und Sand werden stärker als warme Ausdrucksträger genutzt.
- Wissen/Geschichte/Wichtig erhalten zurückhaltende Backstein-/Sand-Tönungen.
- Tipp/Souvenir erhalten warme Bernstein-/Sand-Tönungen.
- Fotospot bleibt etwas kühler, aber auf einer warmen Editorial-Fläche verankert.
- Praktische Infos erhalten eine etwas wärmere Sandfläche.
- Signets übernehmen world-konforme Akzentfarben; keine Rahmen, Divider oder zusätzliche Dekoration.

## Unverändert

- adaptive Layout Grammar
- Hero/Title/Content/Companion/Footer-Zonen
- Extension Capacity Protection
- Companion-Position
- `.nls` 0.10.0
- Fjord Expression

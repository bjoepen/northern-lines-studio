# Build 025C · Ostsee Expression & Companion Fix

Build 025C ist der gezielte traveller-visible Korrekturbuild zum Editorial-World-PoC.

## Ergebnis

- Fischotter-Asset steht im von Tauri/Vite ausgelieferten `public/`-Pfad bereit.
- Ostsee ist visuell klarer von Fjord unterscheidbar, ohne eine andere Layout Grammar einzuführen.
- Shared Signets bleiben semantisch identisch; ihre Farbe folgt der Ostsee-Expression.
- Extension-Flächen nutzen Fog/Sand/Steel/Amber selektiv und rahmenlos.
- Companion Safe Zone, Footer, adaptive Destination Grammar und Content Capacity bleiben invariant.
- `.nls` bleibt 0.10.0.

> Gleiche Sprache. Andere Farbe. Diese Welt.

## Milestone

Build 025C ist offiziell als **Milestone Build** freigegeben. Der Fjord ↔ Ostsee PoC hat bestätigt, dass Editorial Worlds dieselbe semantische und adaptive Grammar teilen können, während Typografie, Companion, Signets und Editorial-Flächen world-spezifisch wechseln. Die Seitenfläche bleibt dabei weiß.

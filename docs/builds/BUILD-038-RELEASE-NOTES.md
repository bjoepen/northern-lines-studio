# Build 038 — Release Notes

## Orientierung

The former user-facing **Inhaltsverzeichnis** is now **Orientierung**. The page is intentionally image-free and remains a calm typographic navigation surface.

## Erinnerungen

The former user-facing **Notizen** page is now **Erinnerungen**. The established writing structure remains intact: one dominant free area plus Schnellnotiz, Ideen and Skizze.

## Soft World Imagery

Fjord and Ostsee Curated Heroes now share the same soft watercolor-edge treatment. The Erinnerungen Curated Accent uses the same open, feathered edge language. Hard rectangular image tiles are no longer part of this grammar.

## Compatibility

No `.nls` migration. Internal page identifiers `contents` and `notes` remain unchanged.

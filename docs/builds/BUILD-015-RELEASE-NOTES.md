# Build 015 – Release Notes

Northern Lines Studio versteht nun nicht nur einzelne Orte, sondern ihre Reihenfolge innerhalb einer Reise.

Der Nutzer ordnet keine Seiten. Er formt **seine Route**. Studio übernimmt die technische Zuordnung im Hintergrund.

Zusätzlich lassen sich Ortsname und Land/Region nachträglich bearbeiten, ohne die stabile Journey-Stage oder den Content-Pfad zu ersetzen.


## Stabilisierung

Die Travelbook-Seitenzahlen folgen nun der tatsächlichen Route. Wird ein Ort früher
oder später in der Reise eingeordnet, ändert sich seine sichtbare Seitenzahl sofort.
Auch alle nachfolgenden Bereiche werden aus der aktuellen Dokumentreihenfolge abgeleitet.

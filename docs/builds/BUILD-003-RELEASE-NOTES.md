# Build 003 Release Notes

Northern Lines Studio 0.3.0 introduces the first semantic Journey Project Model.

### New

- `.nls` project format 0.2.0
- Journey and Journey Stage model
- explicit editorial Page Roles
- semantic workspace grouping
- journey-stage and knowledge context in the Inspector
- in-memory migration of legacy 0.1.0 projects
- expanded Norway reference project

### Preserved

- calm Build-002 visual hierarchy
- Fjord as the only Reference World
- Papageientaucher as Editorial Companion
- static A5 preview

### Not included

No Publisher connection, free layout editor, Knowledge Library editor or PDF export is part of this release.

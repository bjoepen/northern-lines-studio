# Build 033 · Curated Photography Workshop

## Ziel

Der bisher generisch angelegte Fotografie-Workflow wird zu einer vollständig kuratierten, programmneutralen Northern-Lines-Praxisseite.

## Vier Themenwelten

1. **Sehen** — Motiv, Linien, Vordergrund, Tiefe
2. **Gestalten** — Standpunkt, Ausschnitt, Brennweite, Schärfentiefe
3. **Belichten** — Licht, Bewegung, Blende, Zeit, ISO
4. **Unterwegs** — Beobachten, vereinfachen, prüfen, weitergehen

## UX

- keine Authoring-Maske für den Workshop
- keine Softwareauswahl
- keine persönlichen Reisehinweise
- ruhiger Travel-Companion-Inspector mit `kuratiert`, `4 vorhanden`, `nicht vorgesehen`
- sichtbarer Titel: **Fotografie-Workshop**

## Seitenwirkung

Der Workshop übernimmt die gemeinsame Travel-Companion-Geometrie, nutzt aber eine eigene 2×2-Entscheidungskomposition. Die Verbindung zu Licht und Wetter erscheint nur als kurze redaktionelle Brücke.

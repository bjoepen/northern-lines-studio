# Build 019 – Release Notes

Die Reiseplanung kennt nun erstmals den konkreten Rahmen einer Reise.

Start- und Enddatum, Dauer, Ausgangspunkt, Rückkehr, Transport, Routenüberblick und
persönlicher Reisefokus werden strukturiert gespeichert und unmittelbar auf der
Reiseplanungsseite sichtbar.

Northern Lines Studio verwaltet damit nicht nur Seiten und Orte, sondern beginnt die
Reise selbst zu verstehen.

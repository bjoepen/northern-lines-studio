# Build 005 – Release Notes

Northern Lines Studio 0.5.0 introduces the first **Editorial Grammar Foundation**.

Studio can now resolve the editorial grammar of a page and report deterministic Story completeness while keeping the existing calm workspace intact.

Highlights:

- nine Fjord reference grammars;
- Story versus Editorial Frame separation;
- author-facing grammar validation;
- optional-component guidance;
- `.nls` format 0.4.0;
- in-memory migration from 0.3.0, 0.2.0 and 0.1.0;
- no Publisher dependency and no new editing surface.

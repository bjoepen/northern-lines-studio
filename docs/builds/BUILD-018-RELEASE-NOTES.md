# Build 018 – Release Notes

Northern Lines Studio bekommt seinen Reisebegleiter nun auch dort, wo er hingehört:
in die Reise selbst.

Der Fjord-Papageientaucher erscheint erstmals mit der Reiseplanung und begleitet
anschließend Orte, Wissen, Workflows, Notizen und Abschluss. Cover, Willkommen und
Inhaltsverzeichnis bleiben bewusst ruhig.

Zusätzlich wird `Reiseplanung` zu einer echten semantischen Standardseite. Deshalb
steigt das `.nls`-Format auf 0.6.0.

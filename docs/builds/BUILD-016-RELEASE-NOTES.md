# Build 016 – Release Notes

Northern Lines Reisen können nun direkt aus dem Finder geöffnet werden.

Das `.nls`-Format wird unter macOS als Northern-Lines-Reisedokument registriert.
Ein Doppelklick öffnet die Reise entweder in der bereits laufenden Anwendung oder startet
die installierte Northern Lines Studio App.

Der bestehende ProjectSession-Ladeweg bleibt die einzige Quelle für das eigentliche Laden
einer Reise.

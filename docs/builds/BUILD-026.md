# Build 026 · Destination Interest Pages Foundation

Build 026 allows a Destination to grow beyond its main place page without overloading that page.

## Travel Language

> **Was möchtest du in Bergen erleben?**

The author can add one or more of four curated thematic pages:

- **Fotografie**
- **Wandern & Natur**
- **Kultur & Geschichte**
- **Kulinarik & Lokal**

## Product rule

> **Die Destination bleibt das Zentrum. Die Vertiefung folgt dem Interesse der Reise.**

A place can therefore carry, for example, both a Photography page and a Culture & History page. This is intentional and not a conflict.

## Foundation scope

- interest page creation/removal
- destination binding through the Journey Stage
- route-adjacent navigation
- shared Editorial World inheritance
- shared Companion/Footer behaviour
- basic title + introduction authoring
- `.nls` 0.11.0
- migration from 0.10.0

Specialist content modules are deliberately postponed.

# Build 002 – Release Notes

Northern Lines Studio 0.2.0 führt den ersten redaktionellen Workspace ein.

## Neu

- Reference Editorial World `Fjord`
- Editorial Companion `Papageientaucher`
- semantische Travelbook-Navigation
- Editorial Preview Header
- kontextbezogener World-/Page-Inspector
- ruhige Projektstatusleiste
- additive `.nls`-Metadaten für Editorial Worlds

## Kompatibilität

Das `.nls`-Format bleibt auf Version `0.1.0`. Projekte aus Build 001 ohne Editorial-World-Metadaten bleiben gültig.

## Nächster Schritt

Nach der Abnahme von Build 002 folgt nicht automatisch Publisher-Integration. Zuerst wird entschieden, ob das Studio-Projektmodell als nächster Build vertieft wird.

# Build 030 — Culinary & Local Experience

Build 030 turns the fourth approved Destination Interest archetype into a full structured editorial experience.

## Scope

- `+ Empfehlung hinzufügen`
- repeatable culinary/local recommendations
- category / type
- editorial reason: why it is worth discovering
- what to try, discover or take home
- practical guidance
- optional time / price context
- optional place / map reference
- automatic single / two-up / grouped composition
- `comfortable → tight → overflow`
- full active Editorial World expression
- hard Companion and Footer safe zones

## Product boundary

Studio does not become a restaurant database, booking service, review platform or price tracker. The traveller describes a local recommendation; Studio decides how to tell it calmly.

## Project format

The `.nls` format remains `0.14.0`. `DestinationInterestEntry.fields` is already an extensible semantic map, so no migration is required.

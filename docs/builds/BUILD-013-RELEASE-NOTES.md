# Build 013 – Release Notes

Build 013 führt den ersten vollständigen Reisebeginn in Northern Lines Studio ein. Eine neue Reise kann benannt, mit der Fjord Editorial World verbunden und an einem frei gewählten Ort als `.nls` angelegt werden. Beim Journey Beginning begegnet der Nutzer erstmals bewusst dem Papageientaucher als Editorial Companion.

Die aus Build 011 bekannte Svelte-A11y-Warnung des Save-Dialogs wurde gleichzeitig korrigiert: semantischer `div role="dialog"`, Beschreibung, Fokus auf Sichern sowie Escape/Enter-Tastaturverhalten.

# Build 006 – Release Notes

Northern Lines Studio 0.6.0 refines the **Editorial Workspace experience** established by Builds 002–005.

The visible changes are intentionally quiet:

- the oversized lower status area is replaced by a 26 px status line;
- the A5 page uses more of a maximized macOS window;
- resizing remains proportional and centered;
- page changes fade in gently over 190 ms;
- the empty workspace becomes a neutral invitation to begin a journey;
- Inspector surfaces are slightly calmer.

The `.nls` project format remains `0.4.0`; no migration is required for Build 006.

Build 006 adds no DTP tools and no new authoring feature. Its purpose is to make the existing workspace feel more natural in daily use.

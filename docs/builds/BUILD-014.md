# Build 014 – Journey Places Foundation

Version: 0.14.0

## Ziel
Eine selbst angelegte Reise kann erstmals um eigene Orte erweitert werden.

## Enthalten
- Travel Language: `Ort hinzufügen` statt `Seite hinzufügen`.
- Neuer Ortsdialog mit Name und optional Land/Region.
- Persistente Journey Stage vom Typ `destination`.
- Automatisch erzeugte Destination-Seite mit Northern-Lines-Story-Grammar.
- Neue Destination wird unmittelbar geöffnet.
- Build basiert auf dem final validierten Build-013-Stand inklusive Accessibility-Fix (`tabindex=-1`).

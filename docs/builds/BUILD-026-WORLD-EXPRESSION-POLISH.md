# Build 026 · Destination Interest Pages World Expression Polish

## Ziel

Die in Build 026 eingeführten thematischen Vertiefungsseiten erben jetzt die vollständige Expression der aktiven Editorial World. Die Seitenstruktur und Semantik bleiben unverändert.

## Änderungen

- Interest Pages verwenden World-owned Farbrollen statt einer generischen neutralen Foundation-Fläche.
- Fjord bleibt kühl, ruhig und zurückhaltend.
- Ostsee nutzt auf Interest Pages die bereits freigegebene warme Hanse-/Backstein-/Sand-Richtung.
- Die A5-Seitenfläche bleibt in allen Worlds weiß.
- Typografie, Meta-Akzente und Editorial-Flächen wechseln beim World Switch gemeinsam.
- Keine neue Layout Grammar, keine neue Persistenz, keine `.nls`-Migration.

## DoD

Fjord → Ostsee → Fjord auf derselben Interest Page verändert ausschließlich die World Expression; Titel, Einleitung, Destination-Zuordnung, Reihenfolge und Persistenz bleiben unverändert.

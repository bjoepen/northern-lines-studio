# Build 011 Release Notes – Editorial Story Workspace

Build 011 makes semantic authoring feel like a Northern Lines journey rather than a technical editing workflow.

## Highlights
- Reise öffnen / Reise schließen lifecycle
- protected unsaved changes
- editorial Story status beside each component
- human-readable Story progress
- persisted authoring content visible in the A5 preview
- Human Language First architecture decision
- Destination grammar includes Mitbringsel & Souvenirs as a required editorial element

## Unchanged by design
The calm Build-007 visual shell remains intact. There is still no rich-text toolbar, generic object inspector, free-form layout editing or automatic save.

# ADR-010 – Companion Moments

**Status:** accepted

## Entscheidung
Editorial Companions werden nicht als permanente UI-Dekoration eingesetzt. Sie erscheinen an bedeutungsvollen Momenten einer Reise. Build 013 definiert den ersten solchen Moment: die Wahl einer Editorial World beim Beginn einer neuen Reise.

## Konsequenz
Der Companion darf emotional wiedererkennbar werden, ohne Arbeitsfläche oder Authoring zu überlagern.

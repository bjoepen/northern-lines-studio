# ADR-014 – Editorial World Layout Language

## Status
Accepted – Build 017

## Entscheidung

Eine Editorial World besitzt eine eigene Layout Language. Wiederkehrende Gestaltung
wird nicht als Sammlung frei platzierbarer DTP-Objekte auf einzelnen Seiten gespeichert.

Die Fjord Reference World erhält erstmals:

- ruhige Fjord-Farbwerte
- typografische Grundhaltung
- wiederkehrenden Northern-Lines-Footer
- world-spezifische Seitendetails
- drei kontrollierte Destination-Varianten

Der Footer gehört zur Layout Language, nicht zur einzelnen Seite.

## Destination-Vokabular

1. **Weite** – Hero als Banner
2. **Bild links**
3. **Bild rechts**

Build 017 definiert diese Varianten, macht sie aber bewusst noch nicht auswählbar.

## Design Principle

> Wenige starke Layouts. Viele persönliche Geschichten.

## Growth Principle

> Studio wächst mit echten Reisen.

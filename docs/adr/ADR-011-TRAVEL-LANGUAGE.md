# ADR-011 – Travel Language

## Entscheidung
Northern Lines Studio beschreibt das Ziel einer Handlung, nicht ihren technischen Mechanismus.

Der Reisende öffnet eine Reise, fügt einen Ort hinzu und erzählt eine Geschichte. Studio erzeugt intern Projekte, Seiten, Journey Stages und Story Components, ohne diese technische Sprache in den Vordergrund zu stellen.

## Leitsatz
**Der Reisende legt Orte an. Studio baut daraus Seiten.**

# ECR-022 – Destination Imagery Foundation

**Status:** Approved / Implemented

## Request

Build 022 shall introduce real Destination imagery while preserving Northern Lines Studio's Product DNA.

## Approved scope

- optional image roles for **Weite**, **Bild links**, **Bild rechts**;
- simple **Bild auswählen … / Bild ersetzen … / Bild entfernen** workflow;
- contextual `?` geometry help;
- project-local image copies inside `.nls`;
- fast Studio preview without crop;
- format migration to `.nls` 0.9.0;
- 15 mm technical minimum binding zone;
- Companion restored to its invariant Editorial-World position;
- Product-DNA documentation and Consistency Gate coverage.

## Explicit non-goals

- no Asset Management;
- no Crop Editor;
- no Focal Point;
- no drag-and-drop layout;
- no free positioning;
- no gallery;
- no EXIF workflow;
- no new layout variant;
- no new Editorial World.

## Product-DNA check

- Travelbook remains the dominant surface: yes.
- UI speaks Travel Language: yes.
- technical paths remain hidden: yes.
- image geometry help appears only on demand: yes.
- Publisher remains Publishing truth: yes.
- Companion remains unantastbar: yes.

# ECR-004 – Editorial Grammar Foundation

## Motivation

After Build 004, Studio could navigate a Journey and resolve Reference World Fjord, but it could not yet answer a fundamental author-facing question:

> Is this page editorially complete for its purpose?

## Approved change

Build 005 shall:

- introduce an Editorial Grammar Library;
- map Studio pages to a grammar;
- model required and optional Story components;
- model the recurring Editorial Frame separately;
- calculate deterministic Editorial Completeness;
- show missing required components in editorial language;
- keep the interface calm and non-editing;
- extend `.nls` to project format 0.4.0 with Story component presence;
- keep in-memory migration for 0.1.0, 0.2.0 and 0.3.0 projects.

## Explicit non-goals

No text editor, asset browser, free layout manipulation, Publisher bridge, AI scoring, second Editorial World or final renderer is introduced.

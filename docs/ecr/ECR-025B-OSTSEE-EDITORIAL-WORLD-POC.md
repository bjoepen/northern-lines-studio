# ECR-025B · Ostsee Editorial World PoC

## Ziel

Beweisen, dass Editorial World Architektur und nicht ein Fjord-spezifisches Theme ist.

## Scope

- Ostsee als zweite freigegebene Editorial World
- Fischotter aktiv
- persistenter World-Wechsel Fjord ↔ Ostsee
- World-spezifische Typografie und Palette
- Shared Signets, world-spezifische Extension-Flächen
- unveränderte adaptive Layout Grammar und Safe Zones
- farbige Consistency-Statuswörter ohne Emojis

## Nicht im Scope

- neue Page Archetypes
- freie Theme-Konfiguration
- Asset Browser
- neue .nls-Felder

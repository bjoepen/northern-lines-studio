# ECR-011 – Editorial Story Workspace

## Motivation
Build 010.1 established reliable semantic authoring and persistence. The next step is to make that capability feel like working on a story rather than editing individual implementation objects.

## Change
Build 011 introduces the Editorial Story Workspace:

- author-facing Story navigation with editorial status per component,
- dirty-state detection for semantic authoring,
- save / discard / cancel protection before navigation,
- explicit Reise öffnen / Reise schließen lifecycle,
- authored text in the A5 preview,
- understandable Story progress,
- Human Language First UI terminology,
- Destination grammar aligned with the Northern Lines Fieldbook standard, including Mitbringsel & Souvenirs.

## Non-goals
- Rich text formatting
- free layout manipulation
- generic layers or text frames
- automatic save
- Publisher rendering integration
- Companion animation or decorative UI use

# ECR-009 – Story Authoring Foundation

## Motivation
Build 008 gave Studio Story Components. Build 010 makes present Story Components authorable without introducing a generic DTP editor.

## Scope
- semantic authoring domain model
- editorial status lifecycle
- Inspector-based component authoring
- persistence to `project.json`
- format migration 0.4.0 → 0.5.0
- validation and tests

## Out of scope
Rich text formatting, typography controls, free object placement, image picking, collaboration, Publisher rendering and automatic text generation.

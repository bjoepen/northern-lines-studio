# ECR-013 – Journey Opening Foundation

## Ziel
Eine `.nls`-Reise soll sich unter macOS wie ein echtes Dokument verhalten.

## Scope
- `.nls` als eigener macOS-Dokumenttyp
- `.nls` als Package
- Finder-Doppelklick bei geschlossenem Studio
- Finder-Doppelklick bei laufendem Studio
- gemeinsamer ProjectSession-Ladeweg
- Dirty-State-Schutz beim Wechsel auf eine andere Reise
- installierbare `Northern Lines Studio.app`
- dokumentierter Build-/Installationsworkflow

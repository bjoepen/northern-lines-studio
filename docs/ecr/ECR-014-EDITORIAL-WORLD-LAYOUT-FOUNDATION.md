# ECR-014 – Editorial World Layout Foundation

## Ziel
Die Preview soll erstmals sichtbar zur Editorial World einer Reise gehören.

## Scope
- Layout-Domäne
- Fjord Layout Language
- World → Layout Language
- wiederkehrender Footer
- Fjord-Farb- und Seitensprache
- drei vorbereitete Destination-Varianten
- Layout Language im Inspector

## Nicht im Scope
- freies DTP
- frei verschiebbare Objekte
- Bildimport
- Layout-Auswahl
- hunderte Templates

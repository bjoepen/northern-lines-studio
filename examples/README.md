# Examples

## `Norway-Sample.nls`

`Norway-Sample.nls` ist bewusst ein **historisches Legacy-/Migration-Beispiel** und steht im Projektformat `0.5.0`.

Es ist **keine** Vorlage für ein heute neu erzeugtes Northern-Lines-Studio-Projekt und soll nicht auf das aktuelle Format hochgeschrieben werden, solange es als Migration Reference dient.

Das aktuelle `.nls`-Format ist in [`docs/project-format.md`](../docs/project-format.md) dokumentiert.

Für neue reale Reisen gilt der aktuelle Studio-Writer und dessen heutiges Format als Authority. Legacy-Beispiele dürfen ältere Strukturen nur dann behalten, wenn ihr historischer Zweck eindeutig gekennzeichnet ist.

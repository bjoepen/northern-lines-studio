## Asset Contract

Production-ready companion assets should use:

- PNG with real alpha transparency
- quiet, realistic photographic treatment
- no text or speech bubble
- no decorative background
- enough breathing room for editorial placement
- a stable asset ID independent of file name

The original generated source is retained in `companion.png`. Metadata records whether additional cleanup is still required before a production renderer may use the asset.
